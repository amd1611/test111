# Account Forge — Sign-up Assistant

Chrome extension project. See the install and safety notes in this README; the full extension source is in this repository.

## Install
1. Download the repository as a ZIP and extract it.
2. Open `chrome://extensions`.
3. Turn on Developer mode.
4. Choose **Load unpacked** and select the folder containing `manifest.json`.

The extension generates credentials, fills likely registration forms on user action, and pauses for CAPTCHA or identity verification. It is not a universal account creator and should not be used for bulk account creation.
